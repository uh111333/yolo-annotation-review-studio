# yolo-annotation-review-studio
YOLO 图像视频智能预标注与人工复核系统是一套面向计算机视觉数据集构建的桌面标注工具，基于 Python、PyQt5 与 Ultralytics YOLO 实现。系统支持图像与视频文件的浏览、人工画框、类别管理与 YOLO TXT 标签保存，并提供单帧 AI 预标注和视频批量采样预标注能力；支持多分辨率推理与跨尺度结果融合、按类别 NMS、最小目标边长过滤、重叠标注框自动清理以及视频标注帧快速导航。工具在 AI 预标注结果基础上保留人工复核与修正流程，可将视频采样帧导出为图片并生成对应标签文件，适用于目标检测数据集的预标注、复核、补标和规范化导出。
