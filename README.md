# YOLO 图像与视频标注工具

基于 PyQt5、OpenCV 和 Ultralytics YOLO 的本地标注工具，支持图像/视频浏览、人工绘制标注框、YOLO 标签读写，以及单帧和批量 AI 预标注。

## 功能概览

- **图像与视频**：支持 JPG、JPEG、PNG、BMP、TIF、TIFF、WEBP，以及 MP4、AVI、MOV、MKV、WMV、FLV、M4V、WEBM。
- **文件浏览**：递归扫描所选目录；可按文件名或相对路径关键词筛选，并在左侧列表中切换文件。
- **人工标注**：在画面上拖动鼠标左键绘制矩形框；松开后选择目标类别。可在右侧标注列表中选中标注框，双击列表项可修改其类别。
- **类别管理**：可在目标类别选择窗口中新增类别；已有类别按追加方式维护，避免因插入新类别而改变既有类别编号。
- **AI 预标注**：支持当前帧单次推理，以及按采样间隔处理当前视频的批量预标注。
- **多分辨率推理**：可配置多个输入尺寸，分别执行推理后进行跨尺度检测框融合。
- **结果筛选**：可设置置信度、NMS IoU、每帧最大检测数，以及 AI 检测框的最小边长过滤阈值。
- **人工框去重**：绘制新人工框时，可按 IoU 阈值自动移除与新框重叠的旧框。
- **标注导航**：视频中可直接跳转到上一个或下一个包含有效标注框的帧。
- **独立输出目录**：标注结果可保存到单独指定的目录，不会修改原始图像或视频。
- **中文路径支持**：图像读写采用 OpenCV 编码缓冲区方式，兼容 Windows 中文路径。

## 环境要求

- Python 3.9 或更高版本
- PyQt5
- OpenCV
- NumPy
- Ultralytics（仅 AI 预标注需要）

## 安装依赖

```bash
pip install PyQt5 opencv-python numpy ultralytics
```

如果只使用人工标注，可以不安装 `ultralytics`；程序会禁用 AI 预标注相关功能，图像/视频浏览、手动绘框和标签读写仍可使用。

## 启动程序

```bash
python yolo_annotator_fixed.py
```

程序启动时会尝试读取代码中的 `AI_MODEL_PATH`。也可以通过环境变量 `YOLO_MODEL_PATH` 指定默认权重文件，或点击工具栏中的“加载模型”手动选择 `.pt` 权重。

## 基本工作流程

1. 点击“打开文件夹”，选择包含图像或视频的目录。程序会递归扫描支持的媒体文件。
2. 如需 AI 预标注，点击“加载模型”选择 YOLO `.pt` 权重；点击“AI 推理设置”配置推理参数。
3. 在画面中拖动鼠标左键绘制矩形框，并在弹出的目标类别选择窗口中指定类别。
4. 在右侧“当前帧标注列表”中查看和选择标注框；双击某个标注项可以修改类别。
5. 点击“保存标注”，将当前文件的未保存标注写入输出目录。

## 推理设置说明

### 输入分辨率

输入分辨率分为两种互斥模式，设置位于同一个“推理输入分辨率”分组中：

- **单尺度模式**：关闭“启用多分辨率推理与结果融合”，使用“单尺度输入尺寸（imgsz）”。
- **多分辨率模式**：启用该选项后，使用下方的多分辨率尺寸列表；单尺度 `imgsz` 设置会自动变灰并停用，不参与本次推理。

多分辨率尺寸使用英文逗号分隔，例如 `640, 1280, 1920`。启用该模式时至少需要两个不同的尺寸，每个尺寸必须在 320–8192 范围内。不同尺寸的检测结果会映射到原图坐标，再通过按类别 NMS 进行融合。

### 其他参数

- **置信度阈值（conf）**：过滤低置信度候选框。
- **NMS IoU 阈值（IoU）**：控制重复检测框的抑制程度；多分辨率模式下也用于跨尺度结果融合。
- **每帧最大检测数（max_det）**：限制最终保留的检测框数量。
- **最小目标边长**：当检测框的宽度或高度任意一边小于该值时，过滤该 AI 检测框；设为 `0` 表示关闭。该过滤不影响人工绘制的标注框。
- **绘制新框时自动移除重叠标注框**：启用后，绘制新人工框会移除当前帧中 IoU 达到阈值的旧框，不区分类别或来源。可单独调整重叠判定阈值，也可关闭该功能。
- **批量视频采样间隔（帧）**：仅用于批量视频 AI 预标注。例如设置为 `30` 时，会处理第 1、31、61……帧。该参数不影响手动逐帧浏览，也不影响 A/D 标注导航。

推理参数会自动保存，并在后续推理任务中使用。

## 单帧与批量 AI 预标注的区别

- **当前帧 AI 预标注**：推理成功后，以本次结果替换当前帧原有标注；若未检测到目标，则清除当前帧原有标注。推理失败时不会应用结果，也不会清除已有标注。
- **批量 AI 预标注**：按设置的采样间隔扫描当前视频，并将检测结果合并到已有标注中；已有人工标注会保留。同类别且 IoU 达到内部去重阈值的重复检测框不会重复追加。

AI 预标注结果会先进入当前文件的内存缓存，不会自动写入磁盘。请检查结果并点击“保存标注”完成保存。批量处理期间请勿切换文件；可点击“停止批量预标注”结束后续帧处理。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `A` | 跳转到当前视频中上一个包含有效标注框的帧 |
| `D` | 跳转到当前视频中下一个包含有效标注框的帧 |
| `S` | 保存当前文件的标注缓存 |
| `Backspace` | 删除当前选中的标注框 |
| `1–9` | 在目标类别选择窗口中快速选择对应顺序的类别 |
| `F` 或 `Enter` | 确认类别选择 |

`Backspace` 在文件筛选框、数值输入框等文本编辑控件获得焦点时保留原生退格功能，不会删除标注框。

视频逐帧浏览可使用画面下方的进度滑块；A/D 快捷键专用于跳转到前后最近的已标注帧，而不是按固定帧数移动。

## 标注格式与输出结构

程序读写 **YOLO TXT** 标签。每个目标占一行，格式为：

```text
class_id center_x center_y width height
```

其中 `class_id` 为类别编号（从 `0` 开始），中心点坐标以及宽高均相对于图像宽高归一化到 `[0, 1]`。类别名称保存在输出根目录的 `classes.txt` 中，每行对应一个类别编号。

图像标注通常保存为：

```text
输出目录/
├── classes.txt
└── labels/
    └── 相对媒体路径.txt
```

视频标注只导出实际进入标注缓存的帧：抽取的帧图像保存到 `images/`，对应标签保存到 `labels/`。帧文件名包含原视频名称和帧序号。

清空当前画面的全部标注后，程序会保留一个显式的空标注记录。保存时将为该画面写出空 TXT 文件，表示该画面没有目标，可作为 YOLO 负样本。该操作不会删除原始图像或视频。

首次打开数据集时，输出目录默认根据所选媒体目录识别为数据集根目录；也可以点击“设置标注输出目录”单独指定其他位置。更换输出目录不会移动已有文件，之后的保存会写入新目录。

## 标注缓存说明

标注修改和 AI 预标注结果先保存在当前文件的内存缓存中，窗口标题中的星号表示存在未保存修改。

- **清空当前画面标注**：只清空当前图片或视频帧的标注，并将其标记为待保存的空标签。
- **清空未保存标注缓存**：丢弃当前文件的全部未保存修改，再从磁盘恢复当前画面已有标签；不会删除磁盘上已经保存的标签文件。

切换文件或关闭程序时，如当前文件存在未保存修改，程序会提示先保存、放弃修改或取消操作。

## 注意事项

- 程序只保存 YOLO TXT 标签，不提供 VOC XML 导出。
- 当前版本用于手动逐帧浏览和标注，不包含视频自动播放控制。
- 多分辨率推理会对同一帧执行多次模型推理，处理时间和显存占用通常高于单尺度模式；请根据显存情况选择输入尺寸。
